# Reuse the OSRS Wiki DPS engine, so the code is GPL-3.0

Every DPS figure comes from the OSRS Wiki calculator's engine and its item and monster data (weirdgloop/osrs-dps-calc), pulled in and kept up to date with each game update. The engine covers hundreds of special cases (set effects, salve and slayer helm, bolt effects, raid scaling) and is checked against in-game max hits, which a new engine couldn't match for accuracy. The engine is GPL-3.0, so this repo is public under GPL-3.0 and credits the Wiki. Our own code is the budget search, prices, requirements, upgrades and UI.
